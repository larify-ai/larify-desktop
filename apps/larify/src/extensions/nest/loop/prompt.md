# Workflow

```
skills = {
    Explore: `nest-explore`,
    Verify: `nest-verify`,
    Critique: `nest-critique`,
    Reflect: `nest-reflect`
}

phase = Explore

while True:
    do the steps following skills[phase]

    if the verdict stops the loop:
        break

    phase = the phase specified by `Review the Verdict`
```
